Безкоштовна програма-компаньйон для Mac

Завантажте Control My Mac для Mac.

Інсталюйте програму-компаньйон у смузі меню, відкрийте її та відскануйте QR-код програмою на iPhone або iPad. Програма для Mac безкоштовна й потрібна для створення пари.

Завантажити зараз Переглянути на GitHub

macOS 14+ · Apple Silicon · Intel — до версії 1.2.3 · Без облікового запису

Підписано сертифікатом Apple Developer ID і нотаризовано Apple, тож macOS відкриває програму як звичайно.

Потім завантажте програму для iPhone або iPad — вона вже в App Store. Це пульт, а ця безкоштовна програма для Mac — приймач, з яким він створює пару.

开始使用

  1. 下载免费的 Mac 应用，打开 .dmg 并把 Control My Mac 拖到"应用程序"。
  2. 启动它——它驻留在你的菜单栏中，并显示一个二维码。
  3. 授予它请求的一次性 macOS 权限（"辅助功能"，以及如果你打算使用蓝牙的话还有蓝牙）。
  4. 从 App Store 安装 iPhone 与 iPad 应用，让两台设备处于同一 Wi-Fi 网络，或在两者上都打开蓝牙。
  5. 用 iPhone 或 iPad 应用扫描 Mac 上的二维码。配对完成——连接是直接且加密的。

系统要求：iOS/iPadOS 18 或更高版本，macOS 14 或更高版本（Apple Silicon；Intel Mac 最高支持 1.2.3 版）。

配对 & 连接故障排查

iPhone 或 iPad 找不到我的 Mac。

  • 同一 Wi-Fi 网络：确保两台设备处于同一网络——不要一台用 Wi-Fi 而另一台用以太网且位于不同子网之后，也不要用访客网络。访客网络以及某些办公室/酒店网络会阻止设备相互发现（"客户端隔离"）；在那种情况下改用蓝牙。
  • 打开蓝牙：如果你通过蓝牙配对，请确认 iPhone 或 iPad 和 Mac 上的蓝牙都已开启。
  • Mac 应用正在运行：菜单栏图标必须存在，并显示二维码或"就绪"状态。

配对成功了，但什么都连不上（或者会断开）。

  • macOS 防火墙：打开系统设置 → 网络 → 防火墙 → 选项，确保允许 Control My Mac 的传入连接。
  • 本地网络权限（Mac）：在 macOS 15 及更高版本上，检查系统设置 → 隐私与安全性 → 本地网络，确认 Control My Mac 已启用。
  • 本地网络权限（iPhone 或 iPad）：检查设置 → 应用 → Control My Mac → 本地网络是否已开启。iOS 和 iPadOS 只询问一次，如果当时被拒绝，它会静默地阻止发现。
  • VPN：任一设备上的 VPN 都可能把本地流量绕开。暂停 VPN，或启用它的本地网络例外。
  • 还是卡住？退出并重新打开 Mac 应用，在 iPhone 或 iPad 上关掉再打开 Wi-Fi，并试试蓝牙作为交叉验证——这能判断是否是网络的问题。

指针能动，但点击或输入没有反应。

Mac 应用需要"辅助功能"权限才能代你操作。打开系统设置 → 隐私与安全性 → 辅助功能，确认 Control My Mac 已列出并启用。授予之后，退出并重新打开 Mac 应用。

二维码扫不上。

相机权限可能被关掉了——检查设置 → 应用 → Control My Mac → 相机。相机仅用于扫描配对码；详见隐私政策。

Grid、深色模式与重置

应用专属 Grid 是怎么工作的？

使用 Full App 时，每个 Mac 应用都可以拥有自己的 Grid。在 Mac 上把该应用切到前台，打开 Grid，轻点顶部的“… 专用网格”（上面显示的是该应用的名称）。新的 Grid 最初是你的“默认” Grid 的副本。此后只要该应用在前台，它就会自动切换过来，其他应用都使用“默认”。Grid 菜单中的“应用专属网格的工作方式”会在应用内为你讲解。

怎样让 Grid 不再自动切换？

关闭“自动切换”。这个开关就在 Grid 里，位于“重新排列”上方。关闭后，无论哪个应用在前台，你选定的 Grid 都会留在屏幕上。重新打开后，各应用专属的 Grid 又会自动切换过来。

在哪里重命名、调整大小或删除 Grid？

轻点 Grid 顶部的 Grid 名称，即可查看所有 Grid 及其对应的应用。在该菜单或“设置”中的“网格”里打开“管理网格”，就可以重命名 Grid、选择哪些 Mac 应用使用它、设置行数和列数，以及删除它。

如何开启深色模式或更改强调色？

打开“设置”中的“样式”。选择跟随系统、浅色或深色，然后挑选强调色：七种预设之一，或任意你喜欢的颜色。深色模式采用暖色调、低眩光的配色，看起来更舒适。所有方案都可免费使用。

什么是帮助模式？

在帮助模式下，轻点按钮会说明它的用途，而不会真正执行，也不会向 Mac 发送任何内容。新安装的应用在连接 Mac 后会以帮助模式开始。准备好后，轻点任意帮助说明中的“关闭帮助模式”，或使用“设置”中的“帮助模式”开关；你也可以随时在那里重新开启。

如何重置应用？

打开“设置”中的“恢复默认”，从三个选项中选择一个，每个选项都需要确认。“重置设置”会恢复你的设置，并保留你的 Grid、快捷键和预设。“重置设置和自定义内容”还会删除你的 Grid、自定义快捷键、顶部行、预设和布局。“抹掉所有内容”还会忘记已配对的 Mac，让应用像全新安装一样重新开始。你的购买项目始终保留。

方案 & 价格

哪些免费，哪些收费？

Mac 应用完全免费，没有附加条件。iPhone 与 iPad 应用以 Full App 的7 天免费试用开始。试用除非你在结束前取消，否则将以 €4.99/月自动续订——可随时在“设置 → Apple ID → 订阅”中取消，你将停留在Essentials，免费，包含触控板移动、点击、右键点击、Live 和 Draft 键盘基础功能、一个 Grid 按钮以及 Launcher 预览。Full App（€4.99/月或 €19.99 终身）增加了滚动、完整 Grid（包括每个 Mac 应用的专属 Grid 和自动切换）、无升级提示的 Launcher 和窗口切换、Mac 键盘快捷键（包括你自己创建的快捷按钮）、完整手势、预设和微调。深色模式、强调色、帮助模式和“恢复默认”在所有方案中都免费。两种方案都没有广告。付费的 Full App 升级仅在 iPhone & iPad 应用中通过 Apple 购买——在本网站或免费的 Mac 应用中没有任何东西需要付费。

我如何管理或取消订阅？

购买由 Apple 处理。在你的 iPhone 或 iPad 上：设置 → 你的姓名 → 订阅。取消会在当前周期结束时生效；终身买断永不续订。

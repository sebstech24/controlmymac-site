每个 Mac 应用都有专属 Grid

把 Final Cut Pro、Premiere Pro 或 Chrome 切到前台，轻点 Grid 顶部的“… 专用网格”：该应用就会得到自己的 Grid，最初是你的“默认” Grid 的副本。此后只要该应用在前台，它就会自动切换过来。想让选定的 Grid 固定不动？直接在 Grid 里关闭“自动切换”即可。组合键可以从 Mac 学习，也可以手动设置；Grid 按钮和你自己的快捷键还能放进触控板顶部行，一次最多 12 个。

所有 Grid 集中一处

轻点 Grid 的名称，即可查看所有 Grid 及其对应的应用。在“管理网格”（也可在“设置”的“网格”中找到）里，你可以重命名 Grid、选择哪些 Mac 应用使用它、设置行数和列数，或将其删除。“应用专属网格的工作方式”会在应用内为你讲清楚这一切。
